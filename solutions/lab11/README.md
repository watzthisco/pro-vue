# conduit — lab11

A Vue 3 + Vite project.

## Project setup

```
npm install
```

### Compile and hot-reload for development

```
npm run dev
```

### Compile and minify for production

```
npm run build
```

### Run the unit tests

```
npm run test
```

### Lint and fix files

```
npm run lint
```
